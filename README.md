# Campus Lost and Found

A centralized web-based platform for university students to report lost and found belongings. Built with the MERN stack (MongoDB, Express.js, React.js, Node.js).

## Project Status

🚧 Under active development.

## Tech Stack

- **Frontend:** React.js, Vite, JavaScript, React Router, Axios, React Context API, Plain CSS
- **Backend:** Node.js, Express.js, REST API
- **Database:** MongoDB Community Server (local), Mongoose
- **Image Storage:** Cloudinary
- **Authentication:** JWT (HTTP-only cookies), bcrypt, email verification
